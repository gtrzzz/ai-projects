# Panel visual (Fase 1) — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un panel web local (`panel.bat`) para importar vídeos, revisar y ajustar los momentos con vista previa
fiel sin renderizar, renderizar solo lo aprobado y copiar los textos de publicación.

**Architecture:** Servidor FastAPI en `panel/` que reutiliza `clipper.py` y `detector.py`, guarda cada vídeo como
proyecto en disco (`proyectos/<id>/`) y ejecuta lo pesado en una cola de un solo hilo. La página React vive dentro
del paquete `remotion/` (comparte `node_modules`) y usa `@remotion/player` con el mismo componente `Clip` que el
render. La composición vertical pasa de ffmpeg a `Clip.tsx`.

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, python-multipart, pytest, httpx · Remotion 4.0.545,
`@remotion/player` 4.0.545, React 19, Vite, TypeScript · ffmpeg/ffprobe.

**Spec:** `docs/superpowers/specs/2026-11-19-panel-fase1-design.md`

## Global Constraints

- Uso real en Windows 11 + RTX 5070; desarrollo en Mac. Todo lo que dependa de Windows (unidades USB, NVENC,
  CUDA, `.bat`) queda en la lista de verificación de la Tarea 14 para que la pruebe el usuario.
- Todo local y gratis. El servidor escucha solo en `127.0.0.1`, puerto `8765`.
- Interfaz y mensajes en español.
- `procesar.bat`, `instalar.bat` y los comandos de `clipper.py` (`auto`, `lote`, `vertical`, `comparar`,
  `subs`) siguen funcionando. El motor `--motor ffmpeg` no cambia.
- Versiones Remotion fijadas a `4.0.545` (todas las `@remotion/*` iguales).
- Nada se borra automáticamente; solo con el botón *Liberar espacio*.
- Entorno de desarrollo en el Mac: el Python del sistema es 3.9 y no hay ffmpeg. Antes de empezar:
  `brew install python@3.12 ffmpeg` y crear `.venv` con `python3.12 -m venv .venv` (en Mac los ejecutables
  están en `.venv/bin/`).

## Review Focus

1. **Vídeo sin audio o sin voz** (clip mudo, música sin hablar): transcripción vacía, análisis con la voz a peso 0,
   y el panel muestra el proyecto sin errores → test en Tarea 7.
2. **Mismo vídeo importado dos veces** (desde el USB y desde `entrada`, o tras *Liberar espacio*): no duplica
   proyecto; si se liberó, reutiliza transcripción y análisis → tests en Tarea 6.
3. **Cerrar el panel a mitad de un trabajo**: al arrancar, los proyectos en estado `analizando`/`renderizando`
   vuelven a la cola, no se quedan colgados → test en Tarea 7.
4. **Nombres con espacios, tildes o emojis** (capturas de PS5 y vídeos descargados): id seguro, rutas y URLs
   correctas → tests en Tareas 3 y 9.
5. **Momento con fin ≤ inicio o fuera del vídeo** tras editar a mano: se rechaza con mensaje claro, no rompe el
   render → test en Tarea 9.

### Task 4: Composición vertical dentro de Remotion

**Files:**
- Modify: `remotion/src/tipos.ts`, `remotion/src/Clip.tsx`, `remotion/src/Root.tsx`

**Interfaces:**
- Produces: `ClipProps` gana `inicio: number` (s en la fuente), `fin: number`, `modo: "zoom" | "blur" | "recorte" | "base"`,
  `centro: number`, `fuenteAncho: number`, `fuenteAlto: number`. `video` puede ser una URL `http(s)://` (se usa tal
  cual) o una ruta en `public/` (se pasa por `staticFile`). `duracion = fin - inicio`.
- Comportamiento de `modo` (debe verse como el `filtro_vertical` actual de `clipper.py:451`):
  - `zoom`: fondo = mismo vídeo cubriendo 1080×1920, `filter: blur(…) brightness(0.88) saturate(1.2)`, silenciado;
    delante, el vídeo a ancho `1080×1.45` recortado a 1080 de ancho desplazado por `centro`, centrado en vertical.
  - `blur`: igual pero el vídeo de delante **cabe entero** (contain). Para vídeos verticales ocupa toda la
    pantalla: es el formato «Entero (sin recortar)» que el spec llama *original*.
  - `recorte`: un solo vídeo a 1920 de alto, recortado a 1080 de ancho desplazado por `centro`.
  - `base`: el vídeo ya es vertical y compuesto (comparativas, `--voz`): llena la pantalla como ahora.
- Recorte temporal con `trimBefore`/`trimAfter` en frames (en 4.0.545 `startFrom`/`endAt` están obsoletos).
- El zoom con sacudida se aplica al contenedor del vídeo de delante, no al fondo.

**Interfaces:**
- Consumes: T2 (`elegir_segmentos`, `zoom_automatico`, `analisis_a_dict/de_dict`), T3, T5 (`preparar_fuente`),

| Método y ruta | Hace |
|---|---|
| `GET /api/estado` | `{proyectos: [resumen], usb: {nuevos: [ruta]}, entrada: {nuevos: [ruta]}, cola: [...]}`; resumen = id, nombre, duración, estado, progreso, error, nº momentos por estado, bytes liberables |
| `POST /api/importar` `{rutas: [str]}` | encola importaciones |
| `POST /api/subir` (multipart, `archivos`) | `importar_subida` por archivo |
| `GET /api/proyectos/{id}` | proyecto + `palabras` + `curva` (`puntuacion` por segundo) |
| `PATCH /api/proyectos/{id}/opciones` | cambia opciones; si cambia `idioma` borra `transcripcion.json` y `analisis.json` y encola `procesar` |
| `GET /api/proyectos/{id}/props/{mid}` | `props_remotion(render.trabajo_de(...))`: las props exactas que usará el render |
| `POST /api/proyectos/{id}/proponer` | `proponer` con lo guardado (inmediato) |
| `POST /api/proyectos/{id}/momentos` `{inicio, fin}` | crea momento `aprobado`, `editado` |
| `PATCH /api/proyectos/{id}/momentos/{mid}` | campos editables: `inicio, fin, titulo, zoom, zoom_en, estado, subido`; marca `editado` si cambian tiempos/título/zoom |
| `POST /api/proyectos/{id}/renderizar` | encola `render` |
| `POST /api/proyectos/{id}/liberar` | `espacio.liberar`; 409 con el mensaje si no se puede |
| `GET /api/publicar` | momentos renderizados de todos los proyectos con `textos`, `franjas` (próxima por plataforma), `subido`, URL del vídeo |
| `GET/PUT /api/ajustes`, `GET/PUT /api/plantillas` | leer/guardar `ajustes.json` y `plantillas.json` (validando que `plantillas` conserva `hashtags_base`, `cta`, `tipos`) |
| `GET /media/{id}/{archivo}` | ficheros de `proyectos/<id>/` y de la salida, **con soporte de `Range`** (206), sin salir de la carpeta |
| `GET /` y estáticos | `remotion/panel-dist/` |

- Validación de momentos: `0 <= inicio < fin <= duración` y `fin - inicio >= 1`; si no, 422 con mensaje en español.
